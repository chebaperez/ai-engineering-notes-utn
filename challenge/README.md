# 🏆 Proyecto Integrador: Benchmark Challenge (Agentic Financial RAG & Deterministic Tool-Calling)

El **Starter Kit oficial**, el **evaluador offline (`evaluator.py`)**, el **dataset de desarrollo (`dev_set.json`)** y el **contrato formal (`schemas.py` + `server.py`)** se encuentran alojados en el repositorio dedicado del desafío:

👉 **Repositorio Oficial del Challenge:** [chebaperez/aieng-utn-rag-challenge](https://github.com/chebaperez/aieng-utn-rag-challenge)

## Inicio Rápido para Equipos

```bash
git clone https://github.com/chebaperez/aieng-utn-rag-challenge.git
cd aieng-utn-rag-challenge
```

Seguí las instrucciones del `README.md` del repositorio para levantar tu microservicio `POST /solve` y validar tus predicciones localmente antes de conectarte al Evaluador Remoto de la cátedra.
